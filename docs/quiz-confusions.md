# Chants confondables de la Survie

Table fabriquée par `outils/build/quiz-confusions.mjs` à partir de `docs/quiz-confusions-recherche.json`
(recherche du 2026-11-18 dans des guides et sites ornithologiques). Le jeu s'en sert pour choisir les 4 mauvais noms
proposés à côté du bon. **Niveau** : 3 confusion classique, 2 ressemblance réelle, 1 partielle ; 0 = hors du jeu.
Les paires sans source n'entrent pas dans le jeu tant qu'elles ne sont pas validées.
